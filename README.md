# 日本経済モニター(公開ダッシュボード)

このリポジトリは **Public** — GitHub Pagesとして公開するための静的サイトのみを置く。

## ファイル構成

```
japan-economy-dashboard-public/
├── index.html              … ダッシュボード本体(データ取得ロジックは含まない)
├── data/
│   ├── latest.json         … 表示用データ(自動更新、手で編集しない)
│   └── commentary.json     … 解説セクションの文章データ(手動更新)
└── README.md
```

- `index.html` … ダッシュボード本体(データ取得ロジックは含まない)
- `data/latest.json` … 表示用データ。**手で編集しない** — 別リポジトリ
  ([japan-economy-fetcher](https://github.com/))の GitHub Actions が
  毎日自動でこのファイルを書き換えてpushする。
- `data/commentary.json` … ダッシュボード下部の「解説」セクションの文章データ。
  こちらは自動更新ではなく **手動更新**。グラフの動きを見て内容を更新したい時は、
  Claudeに「ダッシュボードの解説を最新のグラフを踏まえて更新して」のように依頼し、
  このファイルを編集してpushする。フィールドは `readingPoints`(短期/中期/長期/国際収支/構造
  それぞれの `{ updatedAt, items }` — 区分ごとに更新日を持つ。短期は日々動くため頻繁に、
  国際収支・構造は年次データの更新に合わせて、というように区分ごとに更新頻度が違う想定)・
  `overall`(全体評価)・`plus`/`minus`(プラス面/マイナス面)・`outlook`(短期/中期/長期の見通し)・
  `updatedAt`(ファイル全体の最終更新日、画面下部に表示)。

`index.html` 内には「国際収支」(唐鎌大輔氏の視点、`BOP_*` 定数)と「構造」(河野龍太郎氏の視点、
`STRUCTURE_*` 定数)の2つの静的データセクションも埋め込まれている。どちらも年次・書籍ベースの
データで手動更新。新しい書籍・分析視点を追加したい時は、同じパターン(定数データ + render関数)で
セクションを増やせる。

セットアップ手順は `japan-economy-fetcher/README.md` を参照。
